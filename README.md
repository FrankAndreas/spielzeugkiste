# Spielzeugkiste

A self-hosted collection of games for children aged about 5–8, made for the iPad, with a laptop browser as the fallback.
Everything is in German, and every screen can be read aloud with the 🔊 button (Web Speech API, `de-DE`).
The app is static: no accounts, no tracking, and it works offline once loaded.
The only server-side part is a small nginx endpoint that logs handwriting traces from Schreiben for debugging (see [docs/deploy-nas.md](docs/deploy-nas.md#handwriting-traces)).

## Games

| Game | What it is |
|---|---|
| 🃏 Memory | Find the pairs, alone or with up to 4 players; three grid sizes |
| 🔍 Unterschiede | Find the 10 differences between two pictures |
| 🎨 Ausmalen | Tap areas of a picture to colour them |
| 🧀 Käseklicker | Tap the cheese |
| 🐍 Schlange | Steer the snake and collect treasures |
| 🍬 Pac-Man | Collect sweets in a maze; choose the speed |
| 🔢 Zahlen | Counting and first sums, up to 9 or up to 20 |
| ✏️ Schreiben | Trace letters and names in the Swiss Basisschrift |
| 🖌️ Malen | Free drawing; pictures are kept on the device |
| 🕵️ Rate mal! | Two kids, two iPads: guess the other's secret animal by asking yes/no questions out loud |

## Development

Requires Node 22 or later.

```bash
npm install      # also installs the git hooks (lefthook)
npm run dev      # http://localhost:5173
npm test         # Vitest
npm run lint     # ESLint
npm run build    # static files in dist/
```

The git hooks run lint and the tests before each commit, and a build before each push.

Stack: Vue 3, Vue Router (hash routing), Pinia and Vite.

## Content

Game content lives in `public/content/` as static files, so most changes need no code:

- `games.json` lists the games and their themes.
- `<game>/<theme>/theme.json` plus pictures (SVG) holds one theme.

To add a theme, create its folder and `theme.json`, then list it in `games.json`.
`src/content.test.js` checks that every theme is complete.

Some content is generated by scripts in `scripts/` (Memory cards, Ausmalen pages, Unterschiede scenes, Schreiben letter paths).
How to run each one is described at the top of its file.

Design notes and plans for each game are in `docs/superpowers/`.

## Deployment

CI builds a Docker image (nginx serving `dist/`) on every push to `main` and publishes it as `ghcr.io/frankandreas/spielzeugkiste:latest`.

```bash
docker compose up -d           # run the published image on port 8084
docker compose up -d --build   # or build from your local checkout
```

To run it on a Synology NAS, with nightly automatic updates, see [docs/deploy-nas.md](docs/deploy-nas.md).
