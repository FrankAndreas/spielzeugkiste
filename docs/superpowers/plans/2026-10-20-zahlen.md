# Zahlen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add "Zahlen" 🔢, an early-math game for counting and adding up to 9 or 20, in six favourite themes, with spoken German and tap-to-count.

**Architecture:** Pure, tested logic in `src/logic/numbers.js` builds a session of 6 tasks, the answer choices, the layouts and the spoken sentences. A Web Audio service plays the counting beats. Small presentational components draw objects, dice, finger hands and answer buttons. `ZahlenGame.vue` runs the task flow: ask, count along, check, cheer or count again, and win. Themes are content folders.

**Tech Stack:** Vue 3 (`<script setup>`), Vue Router (hash), Pinia content store, Vitest + jsdom + @vue/test-utils, Web Speech API via `src/services/tts.js`, Web Audio.

**Spec:** `docs/superpowers/specs/2026-10-20-zahlen-design.md`

## Global Constraints

- Levels: `?level=9` (amounts 0–9) and `?level=20` (amounts up to 20). Default 9. Any other value is treated as 9.
- One session has 6 tasks. Task 1 is always Zählen with 1–5 objects. Tasks 2–6 are the five round types (count, dice, build, plus, listen) in random order, so every session has each type.
- Ranges:
  - **Bis 9:** count 0–9, where 0 is possible but never task 1. Dice: one die, 1–6. Build 1–9. Plus a, b ≥ 1 with a + b ≤ 9. Listen 1–9.
  - **Bis 20:** count 1–20. Dice: two dice, total 2–12. Build 1–20. Plus a, b ≥ 1 with a + b ≤ 20. Listen 1–10.
- Answer choices: exactly 3, distinct, the right one plus two near numbers (±1, ±2), all within 0..level and shuffled.
- Finger picture on answer buttons for 0–10 only; tapping a button speaks its number word.
- Up to 10 objects are placed loosely without overlap. More than 10 are placed in ten-frames: rows of 5, frames of 10.
- A wrong answer never buzzes, scolds or shows red. The app says "Hmm, zähl nochmal mit mir", counts along aloud while highlighting, and the same task stays open. Input is locked while it counts along.
- Speech only through `speak()`; always wait for its Promise before the next sentence. Win card after the last speech + `WIN_PAUSE_MS = 800`.
- Themes: `einhorn`, `prinzessin`, `eisprinzessin`, `feuerwehr`, `ballett`, `musik`. Only emoji; no Disney or film artwork, names or logos.
- Sounds are generated with Web Audio, with no audio files. The game must never throw when there is no `AudioContext`.
- Nothing is loaded from the internet at runtime. Match the surrounding code: aligned assignments, few comments, no semicolons.

## Review Focus

1. **She taps quickly, or taps the same object twice.** The spoken count must never skip or repeat a number. Test in Task 4 (ObjectField).
2. **She leaves the game mid count-along or mid beats.** No further speech, sound or win card may follow. Test in Task 6.
3. **The iPad blocks audio until a tap.** Sound must be unlocked on the first `pointerdown` in the game, and `playBeats` must still resolve when audio is unavailable. Test in Task 3.
4. **She taps answers while the app counts along.** Taps are ignored and nothing is checked twice. Test in Task 6.
5. **Theme files are wrong or incomplete** (missing plural, unknown sound kind). A content test fails before it ships. Test in Task 5.

### Task 2: Session and sentences

**Files:**
- Modify: `src/logic/numbers.js`, `src/logic/numbers.test.js`

**Interfaces:**
- Consumes: `answerChoices`, `numberWord` (Task 1).
- Produces:
  - `parseLevel(value) -> 9 | 20`
  - `buildSession(level: 9|20, kindCount: number, random) -> Task[6]`. Each task has `{ type, answer, kind }` plus:
    - count: `{ amount }`
    - dice: `{ dice: number[] }` (1 die for level 9, 2 for level 20)
    - build: `{ amount, supply }` with `supply = amount + 3`
    - plus: `{ a, b }`
    - listen: `{ amount }`
    - every type except build: `{ choices: number[3] }`

    `kind` is an index into the theme's objects. Plus uses one kind for both groups.
  - `questionText(task, obj) -> string`, where `obj = { one, many }` from the theme. `one` includes its article ("ein Einhorn", "eine Krone"):
    - count: `Wie viele ${many}?`
    - dice: `Wie viele Punkte?`
    - build: `Leg ${n === 1 ? one : numberWord(n) + ' ' + many} in den Korb.`
    - plus: `${group(a)} und ${group(b)}. Wie viele zusammen?`, where `group(1) = one` and otherwise `${numberWord(n)} ${many}`
    - listen: `Hör gut zu! Wie oft?`
  - `cheerText(answer) -> string`: `Super! ${capitalised numberWord(answer)}!`

describe('buildSession', () => {
  it('has 6 tasks: a small count first, then each type once', () => {
    for (const level of [9, 20]) for (let s = 0; s < 30; s++) {
      const t = buildSession(level, 3, seeded(s))
      expect(t).toHaveLength(6)

      expect(t[0].amount).toBeGreaterThanOrEqual(1)

      expect(t.slice(1).map(x => x.type).sort()).toEqual(['build', 'count', 'dice', 'listen', 'plus'])

    }
  })

  it('keeps every answer in the level range', () => {
    for (let s = 0; s < 200; s++) {
      for (const x of buildSession(9, 3, seeded(s))) {
        expect(x.answer).toBeLessThanOrEqual(9)
        if (x.type === 'dice')   { expect(x.dice).toHaveLength(1); expect(x.answer).toBe(x.dice[0]) }
        if (x.type === 'plus')   { expect(x.a).toBeGreaterThanOrEqual(1); expect(x.b).toBeGreaterThanOrEqual(1); expect(x.answer).toBe(x.a + x.b) }
        if (x.type === 'build')  { expect(x.answer).toBeGreaterThanOrEqual(1); expect(x.supply).toBe(x.answer + 3) }
        if (x.type === 'listen') expect(x.answer).toBeGreaterThanOrEqual(1)
        if (x.type !== 'build')  expect(x.choices).toContain(x.answer)
      }
      for (const x of buildSession(20, 3, seeded(s))) {
        expect(x.answer).toBeLessThanOrEqual(20)
        if (x.type === 'count')  expect(x.answer).toBeGreaterThanOrEqual(1)
        if (x.type === 'dice')   { expect(x.dice).toHaveLength(2); expect(x.answer).toBe(x.dice[0] + x.dice[1]) }

    zeros.forEach(([i, type]) => { expect(i).toBeGreaterThan(0); expect(type).toBe('count') })

### Task 3: Sound service

**Files:**
- Create: `src/services/sound.js`, `src/services/sound.test.js`

**Interfaces:**
- Produces:
  - `SOUND_KINDS = ['sparkle', 'bell', 'chime', 'siren', 'piano', 'drum']`
  - `unlockAudio()`: creates the shared `AudioContext` on first call and resumes it. Call it from a user gesture. It is a no-op when `window.AudioContext` and `webkitAudioContext` are missing.
  - `playBeat(kind)`: one short tone (≤ 400 ms), made from oscillators and a gain envelope. It does nothing without a context.
  - `playBeats(kind, n, onBeat, { gapMs = 700, signal }) -> Promise<void>`: calls `playBeat` and then `onBeat(i)` for i = 1..n, `gapMs` apart. It resolves after the last beat plus `gapMs`. If `signal.aborted` is set it stops early, skips the remaining beats and resolves.

- [ ] **Step 1: Write the failing tests.** Use fake timers and no `AudioContext` on `window`:
  - `playBeats('drum', 3, onBeat)`: `onBeat` is called with 1, 2, 3 at 0, 700 and 1400 ms, and the Promise resolves after 2100 ms.
  - Aborting via an `AbortController` after the first beat: `onBeat` is called only once and the Promise resolves.
  - `unlockAudio()` and `playBeat('bell')` don't throw without `AudioContext`.
  - With a stub `AudioContext` class (`createOscillator` and `createGain` returning fakes with `connect`, `start`, `stop` and gain/frequency `AudioParam` fakes, plus `resume`, `currentTime` and `destination`): `unlockAudio()` constructs it once, even when called twice, and calls `resume`. `playBeat` starts at least one oscillator for every kind in `SOUND_KINDS`.
- [ ] **Step 2: Run the tests and watch them fail.**
- [ ] **Step 3: Implement.** Each kind gets its own oscillator type, frequency and envelope:
  - drum: a low sine whose pitch drops
  - siren: a square wave sliding between two pitches
  - bell, chime: high sines with overtones
  - piano: a triangle wave
  - sparkle: quick rising sines

### Task 6: The game view

**Files:**
- Modify: `src/views/games/ZahlenGame.vue`
- Create: `src/views/games/ZahlenGame.test.js`

**Interfaces:**
- Consumes: everything above; `speak` and `stopSpeaking` from tts; `useContentStore().loadTheme('zahlen', id)`.
- Behaviour:
  - **On mount:** load the theme, then call `buildSession(parseLevel(route.query.level), theme.objects.length, Math.random)`. Speak the theme's `tts`, then the first task's question. Also call `unlockAudio()` on the first `pointerdown` on the layout.
  - **Header:** the 🔊 button repeats the current question.
  - **Progress:** 6 stars; done ones are filled.
  - **count, plus:** an `ObjectField` (plus shows two fields with a big "+" between them). Tapping an unmarked object marks it and speaks `numberWord(marked.size)`. Below are the `AnswerChoices`.
  - **dice:** one or two `DiceFace`s with the same tap-count behaviour, then `AnswerChoices`.
  - **listen:** a big pulsing `listen.picture`, a 🔁 button and `AnswerChoices`. After the question, `playBeats(sound, answer, pulse)` runs, and 🔁 replays it. Answers are locked while it plays.
  - **build:**
    - A large digit of the target, a supply `ObjectField` (`supply` objects) and a basket area.
    - Tapping a supply object moves it into the basket and speaks the basket count. Tapping a basket object moves it back and speaks the new count.
    - The basket uses frames when it holds more than 10.
    - A big ✓ button checks the answer.
  - **Pick or ✓:** speak `numberWord(n)` first.
    - **Right:** speak `cheerText`, fill the star, then go to the next task and speak its question.
    - **Wrong:** lock input and speak "Hmm, zähl nochmal mit mir". Then count along:
      - for objects or pips, highlight each one in turn and speak its number word, waiting for each speech;
      - for listen, replay the beats and speak each count;
      - for build, count what is in the basket, then say "Wir brauchen ${numberWord(answer)}."

      Then clear the marks, unlock and stay on the task.
  - **After task 6:** after its cheer and `WIN_PAUSE_MS = 800`, show a win card ("Super gemacht!", 🎉) with "Nochmal" (new session, same level) and "Fertig" (`router.push('/')`). Speak "Super gemacht!".
  - **Leaving:** a `left` flag, a session/task token and an `AbortController` guard every awaited continuation. Unmounting aborts the beats, calls `stopSpeaking()` and sets `left`.
  - Colours come from `theme.colors`.
