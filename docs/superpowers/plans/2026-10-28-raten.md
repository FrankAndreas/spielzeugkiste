# Rate mal! Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A new game "Rate mal!" where each kid uses their own iPad as a board of 24 animals: pick a secret animal, tap away animals while asking questions out loud, then guess.

**Architecture:** Content in `public/content/raten/<theme>/theme.json` (reusing Memory's emoji SVGs). A pure state module `src/logic/raten.js` holds the phases (pick → play → guess → won) and the undo history. A thin view `RatenGame.vue` renders it at `/raten/:theme/play`. No networking.

**Tech Stack:** Vue 3 (`<script setup>`), Vue Router, Pinia content store, Vitest + @vue/test-utils + jsdom.

**Spec:** `docs/superpowers/specs/2026-10-28-raten-design.md`

## Global Constraints

- Game id `raten`, name "Rate mal!", emoji 🕵️, description "Geheimes Tier raten", themes `["bauernhof", "meer"]`.
- Exactly 24 animals per theme, shown 6 columns × 4 rows, **in theme.json order, never shuffled**.
- The secret animal's name is **never spoken**. Tapping a tile (pick or play) speaks nothing and plays no sound.
- All German copy as in the spec: "Wähle dein geheimes Tier! Verrat es nicht 🤫", "✓ Los geht's!", "Dein Tier", "Noch N übrig", "↩ Zurück", "🎯 Ich rate!", "🔄 Neues Spiel", "Ist es {the}?", "🎉 Richtig!", "Falsch", "Abbrechen", "Super! Erraten!", "Nochmal". Spoken on start: "Los geht's! Stell eine Frage."
- Tap targets ≥ 44 px; no hover-only interactions (app-wide rule).
- No new dependencies.

## Review Focus

1. **Both kids pick the same animal.** The board tile of your own secret animal is a normal tile (the other kid may have it too). It can be greyed and guessed like any other. Test in Task 2.
2. **Undo after "Falsch"** brings back the wrongly guessed animal; undo with an empty history does nothing. Test in Task 2.
3. **Taps while the guess dialog is open** must not toggle tiles underneath. Test in Task 3.
4. **"Neues Spiel" / "Nochmal"** clears hidden tiles, the history and the secret; undo right after does nothing. Test in Task 2.
5. **Nothing left to guess:** with 0 animals remaining, "🎯 Ich rate!" is disabled. Test in Task 3.

### Task 2: Game state — `src/logic/raten.js`

**Files:**
- Create: `src/logic/raten.js`
- Test: `src/logic/raten.test.js`

**Interfaces:**
- Produces (all pure; each returns a **new** state object and returns the state unchanged when the action doesn't apply to the current phase):
  - `newGame() → { phase: 'pick', choice: null, secret: null, hidden: [], history: [], guess: null }` — `phase` is one of `'pick' | 'play' | 'guess' | 'won'`
  - `choose(state, id)` — pick phase: sets `choice`
  - `start(state)` — pick phase with a `choice`: `phase: 'play'`, `secret = choice`
  - `toggle(state, id)` — play phase: adds/removes `id` in `hidden`, pushes `id` onto `history`
  - `undo(state)` — play phase: pops the last id from `history` and toggles it back (no new history entry)
  - `remaining(state, ids: string[]) → number` — ids not in `hidden`
  - `startGuess(state)` — play phase → `phase: 'guess'`, `guess: null`
  - `pickGuess(state, id)` — guess phase, `id` not hidden: sets `guess`
  - `cancelGuess(state)` — guess phase → `phase: 'play'`, `guess: null`
  - `answer(state, right: boolean)` — guess phase with a `guess`: right → `phase: 'won'`; wrong → `phase: 'play'`, `guess: null`, guess id added to `hidden` **and** `history` (so undo brings it back)

- [ ] **Step 1: Write the failing tests** in `src/logic/raten.test.js`, one `it` each:
  - `newGame` starts in pick with nothing hidden.
  - `choose` then `choose` again replaces the choice; `start` without a choice stays in pick; `start` with one → `phase 'play'`, `secret` = the choice.
  - `toggle` during pick does nothing; during play: `toggle(s,'kuh')` → `hidden ['kuh']`; toggling again → `hidden []`, `history ['kuh','kuh']`.
  - The secret's own tile toggles like any other (`secret: 'katze'`, `toggle(s,'katze')` → `hidden ['katze']`).
  - `undo` reverts toggles in reverse order; `undo` on empty history returns an equal state.
  - `remaining(s, ['kuh','schaf','katze'])` with `hidden ['kuh']` → `2`.
  - `pickGuess` ignores a hidden id; `cancelGuess` → play, guess null.
  - `answer(s, true)` → `'won'`; `answer(s, false)` → play, guessed id hidden; then `undo` → not hidden.
  - `answer` without a `guess` returns the state unchanged.
  - `newGame()` after a played game: undo does nothing, hidden empty, secret null.

### Task 3: Play screen — `RatenGame.vue` and route

**Files:**
- Create: `src/views/games/RatenGame.vue`
- Modify: `src/router/index.js` (lazy import + `{ path: '/raten/:theme/play', component: RatenGame }`)
- Test: `src/views/games/RatenGame.test.js`

**Interfaces:**
- Consumes: Task 2's functions; `store.loadTheme('raten', theme)` and `store.currentTheme`; `speak` from `services/tts.js`; `AppHeader` with `title="🕵️ Rate mal! — {name}"`, `:tts="theme.tts"`, `color="#8D6E63"`.
- Image URL: `` `/content/raten/${themeId}/${animal.image}` `` (the browser resolves the `../../memory/...` part).
- DOM hooks the tests rely on: tiles `.tile` (with `.off` when hidden, `.chosen` for the pick frame), each containing `img[alt=label]`; `.mine` card; `.count`; buttons `.start`, `.undo`, `.guess`, `.new-game`; dialog `.guess-dialog` with `.right`, `.wrong`, `.cancel`; win overlay `.win` with `.again`.

Screen per phase (layout from the mockup in the spec):
- **pick:** hint line "Wähle dein geheimes Tier! Verrat es nicht 🤫", the 6×4 grid, `.start` "✓ Los geht's!" visible only once `choice` is set. On mount, speak `theme.tts`.
- **play / guess:** grid + right column: `.mine` ("Dein Tier" + the secret's tile and label), `.count` "Noch N übrig", `.undo`, `.guess` (shows as active/pressed in guess phase; tapping it in guess phase cancels; `disabled` when remaining is 0), spacer, `.new-game`. On start, speak "Los geht's! Stell eine Frage." In guess phase without a guess, the hint line reads "Tippe auf das Tier, das du rätst."
- **guess with a guess:** modal `.guess-dialog`: "Ist es {the}?" (speak it once when it opens), big tile, "Was sagt dein Freund?", `.right`, `.wrong`, small `.cancel` "Abbrechen". Tiles under the modal must not react.
- **won:** overlay `.win` with 🎉, "Super! Erraten!" (spoken), `.again` "Nochmal" → `newGame()`, plus a home button (`router.push('/')`).
- Size tiles to fit like `MemoryGame`'s `fitCardSize` (6 cols × 4 rows, minus header and a ~210 px side column), recomputed on resize.
